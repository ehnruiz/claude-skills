# Ticket formats

Each template is a ceiling. Drop a section when it has nothing to say.

## Bug

```markdown
**What happens**
<Who sees what, where, since when. One to three sentences.>

**Why it matters**
<The effect on users, revenue, search, compliance or the team.>

**Done when**
- <Observable outcome>
- <Observable outcome>

**Links**
<label>: <link>
```

## Task

```markdown
**Goal**
<What changes and for whom.>

**Why now**
<The trigger: a deadline, a risk, a dependency.>

**Done when**
- <Observable outcome>
- <Observable outcome>

**Not included**
<One sentence on what is deliberately out of scope.>
```

## Story

```markdown
**As** <a role> **I want** <a capability> **so that** <a benefit>.

**Done when**
- <Observable outcome>
- <Observable outcome>
```

## Spike

Title it `Investigate <question>`.

```markdown
**Question**
<The one question this answers.>

**Timebox**
<Days.>

**Done when**
- A written answer with a recommendation is linked here
```

## Epic

```markdown
**Outcome**
<What is true when every child is done.>

**Children**
Listed on the board. Each child holds its own detail.
```

## Technical notes comment

```markdown
**Technical notes**

Cause: <root cause, with file paths>
Approach: <suggested change>
Verify: <command, test or page to check>
```
